\section*{Introduction}

This document presents the results of implementing Singular Value Decomposition (SVD) using custom algorithms and compares them with NumPy's built-in SVD functionality. The primary focus is on performance metrics and accuracy of the decomposition.

\section*{Methodology}

The custom SVD implementation utilizes Householder reflections for QR factorization and the QR algorithm for eigen-decomposition of $A^T A$. The overall algorithm follows these steps:

\begin{enumerate}
    \item Compute $A^T A$.
    \item Apply the QR algorithm to find the eigenvalues and eigenvectors of $A^T A$.
    \item This gives us $A^T A = V \Lambda V^T$.
    \item Sort the eigenvalues in descending order to obtain the singular values.
    \item By definition, $\Sigma = \sqrt{\Lambda}$, and $U\Sigma = A V$.
    \item Then, it is straightforawrd to get $U$ since $\Sigma$ is diagonal.
\end{enumerate}

NumPy's optimized \texttt{numpy.linalg.svd} function is used as a benchmark for comparison in time. Another error metric is the reconstruction error $\| A - U \Sigma V^T \|$.
